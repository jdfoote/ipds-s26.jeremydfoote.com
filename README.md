# Intro to Programming and Data Science (Spring 2026)

This is the course website for COM 674: Introduction to Programming and Data Science at Purdue University.

## Building the Site

This site is built with [Quarto](https://quarto.org/). To build the site locally:

```bash
quarto preview
```

To render the full site:

```bash
quarto render
```

## Structure

- `index.qmd` - Homepage
- `syllabus/` - Course syllabus
- `schedule/` - Weekly schedule pages
- `schedule.qmd` - Schedule overview
- `assignments/` - Assignment descriptions
- `day_*/` - Daily lecture materials and notebooks
- `resources/` - CSS and other resources
